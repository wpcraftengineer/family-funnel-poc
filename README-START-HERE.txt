FAMILY FUNNEL - SAMPLE ASSIGNMENT POC
Prepared for Mahesh Sharma

OPEN THE DEMO
1. Extract the entire ZIP into one folder.
2. Double-click index.html. Keep the CSS, JavaScript, thank-you page and PDF alongside it.
3. Enter fictional name/email and select an income answer.
4. Over $100,000: the optional consultation offer appears. Select it to show callback fields.
5. Other answers: the guide remains available, without an advisor request.
6. Submit to see the thank-you route and download the sample PDF.

This is a standalone frontend POC, not an installable WordPress plugin or a WPForms export.
No backend, emails, Zapier, CRM or Meta Pixel is connected. No form data is saved or transmitted. Only the demo route and consultation yes/no flags appear in the URL.

QUALIFICATION RULE
The speaker uses income over $100,000 as an example. This POC demonstrates that example only. Confirm the real questions, threshold, exact boundary and treatment of unanswered questions with the client before live setup. Qualification for marketing follow-up is not insurance underwriting or coverage eligibility.

WORDPRESS FILES
Keep your existing theme, functions.php and plugins active. This demo replaces none of them. No require_once lines are needed. Do not upload this ZIP using Plugins > Add New. Use it as a reference for implementing the pages and form on staging.
